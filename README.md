I'm a **DevOps Engineer & Site Reliability Engineer** focused on designing, automating, and operating **scalable, highly available, secure, and cost-efficient infrastructure**.

I work across **AWS, Azure, and GCP**, with a strong focus on cloud infrastructure, Kubernetes, GitOps, Infrastructure as Code, CI/CD, observability, automation, production reliability, and incident troubleshooting.
